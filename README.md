One sentence, at most 200 characters, explaining the modern internet to
a time traveler who has just stepped out of the year 1800 — pictured as
a printing press that prints every person's thoughts the moment they
think them, so all the world reads one endless paper, and any soul may
add a line to it.

`main.py` (Python standard library only) writes that single sentence to
`/output/entry.txt`.
